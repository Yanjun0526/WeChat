\chapter{Implementation Pipeline and Reproducibility}
\label{app:implementation-reproducibility}

This appendix summarises the implementation pipeline and validation checks used to produce the three empirical datasets and generated result tables. It is intended as a self-contained record of the reproducibility materials retained with the dissertation.

\label{app:b-pipeline-overview}

The implementation follows the four-stage structure described in Chapter~\ref{chap:data-processing-and-feature-construction}. Table~\ref{tab:app-b-pipeline-overview} summarises the purpose and retained outputs of each stage.
